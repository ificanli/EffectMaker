# EXP-2026-022：特效Orange女娲四技能节奏与Stencil显隐验证

## 目的

验证停顿/冲刺/回弹节奏、地面 Mask 挖空和 Stencil/深度显隐是否共同提升空间层次与技能可读性。

## 对照组

- `Nuwa4_A`：匀速移动、无停顿、直接展开到峰值、无地面参照。
- `Nuwa4_B`：出现—停顿—冲刺—爆发，峰值后小回弹。
- `Nuwa4_C`：B + 主体/边缘/底部/流光分层和黑白 Mask 挖空。
- `Nuwa4_D`：C + 参照对象写入 Stencil、主体按匹配条件显隐。
- `Nuwa4_E`：D + 地面圈选与不同相机角度测试，验证空间显隐迁移。
- `Nuwa4_F`：Stencil 值不匹配、深度测试错误、Mask 过硬或渲染顺序错误的反例。

## 观察指标

- 节奏是否比匀速更有蓄力和爆发。
- 回弹是否增强弹性而不产生多余抖动。
- 地面挖空和穿地是否具有清楚的深度关系。
- Stencil 显隐是否随相机和对象位置稳定工作。
- Mask、透明叠加和深度设置是否引入边缘断裂、穿插或过曝。

## 通过标准

1. B 比 A 更容易读出蓄力到释放的节奏。
2. C 能明确区分主体、底部和地面空间层。
3. D/E 在至少两个相机角度下保持预期显隐。
4. F 能复现模板值、深度或排序错误的负面表现。
5. 结果绑定 Unity 版本、Shader/材质配置、录屏/截图和性能数据。

## 当前状态

`planned`。当前无可运行 Unity 工程，尚未执行；结论保持 `experimental`。
