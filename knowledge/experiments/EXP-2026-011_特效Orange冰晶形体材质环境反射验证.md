# EXP-2026-011：特效Orange冰晶形体、材质与环境反射验证

## 目的

验证冰晶的基础几何、FFD/软选择造型、主贴图明暗结构、Fresnel、Cubemap 环境反射和边缘控制是否分别承担预期职责。

## 对照组

- `OrangeIce_ShapeA`：八面体基础形体。
- `OrangeIce_ShapeB`：十二面体基础形体 + FFD/软选择。
- `OrangeIce_MaterialA`：基础色 + 明暗渐变。
- `OrangeIce_MaterialB`：基础色 + 明暗渐变 + Fresnel。
- `OrangeIce_MaterialC`：B + Cubemap 环境反射。
- `OrangeIce_EdgeA/B`：普通软选择弱化边缘 / 反向软选择强调边缘。

## 固定变量

摄像机、地面、灯光、动作、分辨率、播放时长、平台和目标 Unity/渲染管线固定；每次只改变一个变量。

## 观察指标

- 冰晶尖厚比例、面感、地面贴合和局部起伏。
- 明暗渐变的根部/主体/亮边层次。
- Fresnel 是否只补边缘而未洗白主体。
- Cubemap 是否增加可信的环境高光和内部细节，是否过曝。
- 普通/反向软选择对边缘自然度和可读性的影响。
- 网格面数、材质数量、透明过绘和帧时间。

## 通过标准

1. 形体对照能区分面数和 FFD/软选择的职责。
2. 材质对照能分辨基础渐变、边缘光和环境反射的独立贡献。
3. 边缘弱化与强调都能按设计目标稳定控制，不出现硬切或过曝。
4. 结论绑定 Unity 版本、渲染管线、目标平台及截图/录屏证据。
