# EXP-2026-141 雷电四层技术基线 R001

## 目标

将旧的单层 `particle_v1` 雷电候选升级为可独立训练的四层 PrefabGraph，不把技术可见性当作专业审美结论。

## 结构与资产

`lightning_family_adapter.v1` 生成：

- `MainBolt / core`：主体电弧；
- `BranchSupport / support`：较弱分叉；
- `ImpactFlash / hit`：前端瞬时亮点；
- `ResidualSpark / residual`：命中后的短时余电。

资产来自权威 EffectDemo：

- 材质模板：`Assets/QFX/ProjectilesFX/VFX_Resources/Materials/Nature/MFX_Flare_4.mat`；
- 主电弧：`Assets/Epic Toon FX/Textures/lightning2.png`；
- 支撑分叉：`Assets/Epic Toon FX/Textures/lightning1.png`；
- 命中：`Assets/QFX/ProjectilesFX/VFX_Resources/Textures/Other/FX_Hit_1.png`；
- 残留：`Assets/QFX/ProjectilesFX/VFX_Resources/Textures/Other/FX_Spark_1.png`。

同步到隔离工程的两张 Lightning 贴图及 `.meta` 均通过 SHA-256 一致性检查。

## 结果

`layered_lightning_family_r001` 使用 8 个 seed：

- PrefabGraph Schema：`8/8`；
- Unity 编译与保存后贴图回读：`8/8`；
- Prefab API 回读：`8/8`；
- Play Mode 连续帧：`8/8`；
- 材质错误：`0`；
- 每个候选有效帧：`25`。

实际帧已显示可识别的蓝白折线电弧和辉光，但当前主体仍偏图标化，分叉与主电流的粗细层级尚未经过专业 Teacher。因此注册表状态为 `technical_adapter`，不进入正向审美训练。
