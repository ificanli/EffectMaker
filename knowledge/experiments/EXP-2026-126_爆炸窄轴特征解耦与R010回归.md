# EXP-2026-126 爆炸窄轴特征解耦与 R010 回归

## 问题

R010 只把 Core 从均匀光盘替换为结构化软边纹理，四层参数中的 Shockwave、Debris 和 Residual 均未改变。R010 为 `8/8` Unity 技术通过，但旧模型得到：

- Core：`1/8` 分布内；
- Residual：`0/8` 分布内；
- Shockwave：`0/8` 分布内；
- Debris：`0/8` 分布内。

旧 Residual、Shockwave 和 Debris 模型都把完整时段的全图统计拼入各自特征。Core 材质变化因此同时改变所有轴的输入，造成跨层 OOD。

## 修复

- Residual v2：只保留非残留层结束后的晚段活跃、面积、最后可见时间、中心亮度和局部对比特征。
- Shockwave v2：只保留冲击环窗口的面积、初始/峰值半径、半径增长和单调性。
- Debris v2：只保留碎片窗口，并屏蔽中心归一化半径 `<0.12` 的像素，再统计离散组件、径向范围和面积。
- 三个模型均升级 dataset/model schema；旧 checkpoint 原样保留，不与新特征顺序混用。

## 同帧复验

新模型复用 R010 完全相同的 `640x640`、固定正交、2.5 秒 Play Mode 帧，不重新渲染：

| 轴 | 旧模型分布内 | 轴局部模型分布内 |
|---|---:|---:|
| Shockwave | 0/8 | 8/8 |
| Debris | 0/8 | 8/8 |
| Residual | 0/8 | 0/8（首次，采样协议不匹配） |

Shockwave 与 Debris 的恢复证明全图特征污染已被消除。Residual 首次仍为 OOD，进一步检查发现训练捕获使用 `512x512 / 0.05s`，R010 综合捕获使用 `640x640 / 0.025s`；活跃帧比例本身会受采样间隔影响。随后新增 `residual_fixed_orthographic_v1`，将 R010 的 8 对 Residual 消融加入训练，合并为 `16` 对/`32` 条，并重新使用匹配协议捕获 R010，结果恢复为 `8/8` 分布内。

## 结论

材质变更不能再通过全图特征间接改变非目标轴评分。Shockwave、Debris 和 Residual 已采用轴局部输入及各自固定捕获协议。由于 R010 已参与 Residual 扩样，它只能证明修复有效，不能作为最终独立泛化证据。Core 纹理 Teacher 已验证，但结构化纹理仍是 gated 候选，必须先训练 Core 材质排序头并用 R011 完成新的独立四层回归。
