# EXP-2026-004：烟花生命周期分层验证

## 目的

验证发射、上升、爆炸、放射和残留分层，是否比单一粒子系统更容易控制节奏、主体和收尾。

## 实际验证环境

- 工程：`E:/UnityVFX/EffectDemo6.0`
- Unity：`6000.5.9f1`
- URP：`17.5.0`
- Pipeline：`com.unity.pipeline 0.5.0-exp.1`
- 场景：`Assets/Scenes/SampleScene.unity`
- Endpoint：`127.0.0.1:7800`

## 实际执行

1. 通过 `create_fireworks_particles` 创建 `Fireworks` 下的五个阶段：`Launch`、`AscentTrail`、`ExplosionCore`、`RadialBranches`、`Residue`。
2. 命令返回 `particleSystemsCreated: 5`、`saved: true`；重复执行时返回 `particleSystemsCreated: 0`，证明创建命令幂等。
3. 通过五个独立命令配置全部阶段，避免批量操作 `ParticleSystem` 模块；随后在视觉复核中放大粒子并错开阶段时序：
   - `configure_fireworks_launch`：duration `1.0s`，lifetime `0.65–1.0s`，speed `5.6–7.0`，size `0.14–0.22`，黄色，delay `0`。
   - `configure_fireworks_ascent`：duration `0.9s`，lifetime `0.35–0.7s`，speed `0.35–0.8`，size `0.08–0.14`，橙色，Burst `24`，delay `0.15s`。
   - `configure_fireworks_core`：duration `0.45s`，lifetime `0.22–0.45s`，speed `0.8–1.4`，size `0.35–0.6`，白色，Burst `16`，delay `0.75s`。
   - `configure_fireworks_radial`：duration `1.5s`，lifetime `0.7–1.5s`，speed `3.2–5.2`，size `0.12–0.22`，红橙色，Burst `64`，Sphere Shape，delay `0.78s`。
   - `configure_fireworks_residue`：duration `2.1s`，lifetime `0.9–2.1s`，speed `0.45–1.1`，size `0.07–0.14`，深红色，Burst `20`，delay `0.82s`。
4. 五个配置命令和 `configure_fireworks_visuals` 均返回保存成功；五层绑定三种 URP `Universal Render Pipeline/Particles/Unlit` 材质：Core、Warm、Residue。
5. 通过 `set_material_properties` 将三种材质设置为透明队列 `3000`、`_ZWrite=0`、透明混合；通过 Renderer 回读确认五层材质引用完整。
6. 通过 `get_material_properties` 回读三种材质 Shader、颜色、Emission 和透明参数。
7. 通过 `get_component_properties` 逐个读取五个 ParticleSystem，确认 duration、looping、playOnAwake 和材质引用已保存。
8. 通过 `editor_play` 确认进入 `playing`，再调用 `play_fireworks` 显式播放五层；分别在运行时间约 `0.65s`、`0.90s`、`1.60s` 抓取 1280×720 Game 截图。
9. 三张截图的像素差异区域分别覆盖约 `(294,21)-(1174,520)` 和 `(384,21)-(1174,498)`，证明画面随生命周期变化；截图已保存于 `E:/UnityVFX/EffectDemo6.0/Temp/pipeline-screenshots/`。
10. 读取性能统计：`drawCalls=39`、`setPassCalls=32`、`triangles=10407`、`cpuFrameTimeMs=10.3369`、`gpuFrameTimeMs=1.912832`；这是当前编辑器基线，不替代目标设备测试。
11. 通过 `editor_stop` 退出 Play Mode，最终状态恢复 `ready/stopped`；`unity projects verify` 结果 `errors: 0`、`warnings: 0`、`filesScanned: 127`。

- 层级证据：`get_scene_hierarchy`。
- 参数证据：对五个阶段分别执行 `get_component_properties`。
- 运行证据：`editor_play` / `editor_status` / `editor_stop`。
- 工程证据：`unity projects verify` 返回 0 errors、0 warnings。

## 结论

`verified`（五阶段参数、材质绑定与运行截图闭环）。五阶段对象、粒子组件、独立生命周期参数和三种 URP 透明材质已在 ASCII 主工程中真实创建、保存、读取并通过 Play Mode；显式播放后截图出现随时间变化的烟花画面，性能统计已记录。该结论不代表课程镜头的美术级复刻或目标设备性能已经达标。

## 限制与后续

- 当前使用无外部贴图的 URP Unlit 材质，尚未加入序列帧、Noise、Mask、拖尾纹理或自定义 Shader。
- 截图已证明生命周期和画面变化，但仍需人工查看 PNG 的主体轮廓、峰值位置、颜色层级和残留收束，当前自动像素检查不能替代审美判断。
- 性能数据是 Unity 编辑器基线，不替代目标设备测试；透明 Overdraw 尚未单独测量。
- `ParticleSystem` 的 Generic 模块在通用读取接口中显示为 unsupported；Emission、Shape、Start Delay 等模块通过自定义命令设置，顶层生命周期和 Renderer 材质通过 Pipeline 回读验证。
- 编译/域重载期间 Pipeline 曾短暂断连；等待 `editor_status=ready` 后命令注册和执行均成功，未产生 Console 错误。
