# EXP-2026-133 刀光方向拖带技术基线 R005

## 目标

在已经验证的 `OuterBlade + InnerSupport` 双层刀光上增加 `DirectionTrail`，为“拖带应沿攻击方向，而不是原地堆叠或朝镜头运动”建立后续受控实验底座。

## 实现

- `OuterBlade`、`InnerSupport` 继续使用 `Slash4.fbx` Mesh；
- `DirectionTrail` 使用 Billboard 粒子、`Trail68.png` 和 QFX 粒子材质；
- DirectionTrail 节点绕 Y 轴旋转 90 度，使局部 Z 发射方向投影到画面 X 轴；
- 生命周期约 `0.18-0.20s`，启动延迟 `0.025s`，速度约 `1.8-2.1`。

## 技术结果

- Unity 编译：`8/8`；
- Mesh 路径回读：`8/8`；
- Prefab API 回读：`8/8`；
- Play Mode 可见：`8/8`；
- 材质渲染错误：`0`。

当前合成画面中主刃占主导，DirectionTrail 与主体有重叠，不能仅凭完整画面确认运动方向。因此 R005 只标记为技术成功，拖带层继续保持 `ai_hypothesis`。下一阶段将关闭主刃/内层，只对 DirectionTrail 做沿攻击轴与朝镜头轴的单变量 A/B，并用像素质心横向位移验证。
