# EXP-2026-128 结构化 Core 可读性与 R012 五轴回归

## 结构化 Core 数据

以 R011 的 8 个结构化 Core 候选为正例，生成同拓扑 Core Alpha=0 基线。捕获固定 `640x640`、正交尺寸 `1.5`，模型只读取 Support 启动前的早期中心区域。

结果：

- Unity 编译、贴图回读、Prefab API 回读、Play Mode：`8/8`；
- Core readability 专业规则：`8/8`；
- 中心亮度增益：`0.49-0.58`；
- 中心局部对比增益：`0.44-0.46`。

训练数据为 8 对/16 条，pair 级 `4/2/2`，泄漏 0。`professional_core_rule_ranker_r003_structured` 使用 Core-only 局部特征、AdamW 和成对 softplus 损失，三分区 pair accuracy 均为 1.0。

## R012

R012 使用全新 seed 和显式结构化纹理档位。每个候选都经过资产闭包、Unity 2022 编译、Prefab API 回读和各轴固定协议 Play Mode 捕获。

五轴分布门禁均为 `8/8`：Core readability、Core material、Shockwave、Debris、Residual。该结果证明结构化 Core 档位能够与现有四层爆炸兼容，但不证明整体节奏或综合审美已经完成。
