## 数据与模型

## 独立回归

R008 使用新 Prompt 和 seed `20261404-20261411`，完成 `8/8` Unity 编译、Prefab API 回读和固定正交 Play Mode 捕获。模型结果为：

- 分布内：`5/8`；
- OOD：`3/8`，保持排除，不强行评分；
- 分布内 Top-1：`layered_explosion_005_pfg_f869b1150f3a357791c4`。

这说明模型已具备部分新 seed 泛化能力，但训练集对随机碎片布局的覆盖仍不足。没有放宽 OOD 阈值，而是把已经完成独立评估的 R008 转为第二批 8 对消融数据：该批 `8/8` 技术通过、`8/8` 专业规则通过。两批合并为 `professional_debris_rule_training_r002`，共 `16` 对/`32` 条，pair 级 train/validation/test=`8/4/4`，泄漏为 0。

`professional_debris_rule_ranker_r002` 的三分区 pair accuracy 均为 `1.0`。随后生成完全未参与训练的 R009，使用 seed `20261504-20261511`：
