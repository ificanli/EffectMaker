# EXP-2026-010：特效Orange刀光节奏与分层贴图对照验证

## 目的

验证特效Orange关于“节奏曲线决定打击感”“亮层需要暗层支撑”“主体/色彩/亮层分离”和“过强流速会拉丝”的可迁移性。

## 对照组

- `OrangeSlash_A`: 单层模型 + 固定颜色 + 线性透明度。
- `OrangeSlash_B`: 同一模型 + 快入慢出高光曲线 + 暗层支撑。
- `OrangeSlash_C`: 主体层 + 色彩层 + 独立亮层 + 低强度噪声流动。
- `OrangeSlash_D`: 与 C 相同，但提高流速和偏移，作为拉丝反例。

## 固定变量

动作轨迹、模型、摄像机、背景、光照、分辨率、播放时长和目标平台固定。每次只改变一个变量。

## 观察指标

- 起势、命中、可读窗口和收尾是否清楚。
- 高光峰值是否集中，暗层是否托住亮层。
- 主体、色彩和亮层是否能独立调节。
- 流速增加后是否出现拉丝、形体破坏或信息丢失。
- Draw Call、透明过绘、材质数量和帧时间。

## 通过标准

1. B 比 A 更容易读出命中峰值和收尾过程。
2. C 比单层版本更容易独立调整颜色和高光，不破坏主体轮廓。
3. D 能明确显示流速过强导致的拉丝或可读性下降。
4. 结论必须绑定 Unity 版本、渲染管线、目标平台和录屏/截图证据。
