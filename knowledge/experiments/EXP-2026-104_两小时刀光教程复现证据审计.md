## 已有直接证据

以下结论可以绑定到教程字幕或视觉复核记录，并可作为制作原则使用：

- 快速进入/命中、短峰值、慢速退出，残留层独立控制时间。
- 主色、辅助色、点缀色按职责分层；`60/30/10` 是案例示例，不是固定生产参数。
- 从空 Particle System 搭载模型开始；主体使用平面/模型、Local 空间、方向和尺寸调整。
- 网格长度、宽度和细分必须支持点变形，避免低细分拉伸。
- 使用 Mask、方向调整、`90°` 旋转、Custom Data 曲线和 UV Offset 修正。
- 暗/灰支撑层更低、更暗、更慢、更长；亮层局部出现；快速打击层接近目标或命中点出现。
- 后段包含点光、地面平面/路径反馈、黑白可见性 Mask 和 Size 三曲线等方法。

## 第二轮补学结果：70:00–90:00

本轮修正了上一轮的处理错误：旧脚本曾把错误的 `01:10–01:20` 音频标记为 `70:00–80:00`，并未准确处理 `80:00–90:00`。现已从完整 `BV1mjvxBgESJ_16k_mono.wav` 按绝对时间切出真实的 `70:00–80:00` 和 `80:00–90:00` 音频，并使用本地缓存的 Whisper small 模型重新生成：

- `transcripts/BV1mjvxBgESJ_70-80_audio_relearn.srt`
- `transcripts/BV1mjvxBgESJ_80-90_audio_relearn.srt`

新增的高置信教程事实：

- `70:00–72:50`：复制刀光层和材质，建立暗底层；暗层使用 Alpha 模式，颜色整体更暗，但过暗会发脏，需要回调；暗层溶解更明显、更柔和，并下移层级。
- `73:00–75:45`：主体速度过快时需要回调整体节奏和位移；基础主层完成后再开始快速打击层。
- `76:20–77:25`：快速打击层不是与主体同时出现，而是在刀光接近目标/命中位置时才逐渐显现；明确有“两小层”承担该打击反馈。
- `77:25–79:20`：快速打击层使用比主体更简单的贴图，复制对象后清空原材质功能，只保留一张贴图；调整 X 轴尺寸/流动、整体大小和位置；通过 Custom Data X 轴控制位移，关闭不需要的轴向控制；加入 `0.1` 延迟。
- `79:20–80:00`：单向 Mask 用于修正两侧遮罩和方向，字幕中出现 `180`、`270` 的方向试验；位置偏差必须单独修正。
- `80:00–82:30`：Mask 方向继续试验，`90°` 立起；通过额外遮罩叠加只保留局部；黑色区域遮掉模型，保留小部分可见区域；重点是反复调整 UV 方向，而不是盲目增加强度。
- `81:45–82:50`：高光使用 Bloom/颜色处理时出现过曝会吞掉细节；亮度需要回调，必要时提高少量饱和度以保留颜色。
- `83:00–84:30`：复制主体层增加小暗层，改为 Alpha 模式并关闭不需要的功能；该层位于主体层下方、但仍需保持相对其他层的顺序；可用自定义曲线让 UV 流动错开或延迟。
- `85:30–86:30`：刀光本体强度和氛围光是两个独立问题；氛围可由小气浪和小氛围光承担，不能用主体强度代替氛围设计。
- `87:25–89:00`：辅助层可使用一张简单的剑片贴图和 Add 模式；贴图可旋转 `180°`，再用遮罩控制只留下局部；遮罩不足时可以叠加第二层遮罩。

这些内容可以进入 `tutorial_fact`，但没有补足 Shader 名称、材质名、纹理资产名、完整对象数量或完整 Inspector 曲线值。字幕中的个别 ASR 术语仍需与画面复核，不能把听写字面直接当作字段名称。
