# EXP-2026-002：场景搭建基线对照验证

## 目的

验证场景参照、角色占位、摄像机、特效根节点和生命周期分层能在 Unity 6 工程中创建、保存、重新读取并进入 Play Mode。

## 实际验证环境

- 工程：`E:/Unity特效人工智能学习/UnityDemo/EffectDemo6.0`
- Unity：`6000.5.9f1`
- 渲染管线：URP `17.5.0`
- 目标平台：`StandaloneWindows64`
- Pipeline：`com.unity.pipeline 0.5.0-exp.1`
- CLI/Pipeline endpoint：`127.0.0.1:7800`
- 场景：`Assets/Scenes/SampleScene.unity`

## 实际执行

1. 通过 Unity Pipeline CLI 创建 `VFX_Verification` 根对象。
2. 创建 `EnvironmentReference` 平面，缩放 `[5,5,5]`。
3. 创建 `ActorReference` 胶囊，占位位置 `[0,1,0]`。
4. 创建 `EffectRoot`，并建立 `Prelude/Core/Burst/Residue` 四阶段节点。
5. 给 `Burst` 添加 `ParticleSystem`。
6. 通过工程注册命令 `configure_burst` 配置粒子：
   - looping：`false`
   - playOnAwake：`false`
   - duration：`1.2s`
   - burst count：`32`
   - start speed：`2.5–4`
   - start lifetime：`0.8–1.2s`
   - start size：`0.08–0.18`
   - start color：橙色 `[1, 0.45, 0.08, 1]`
6. 通过 `save_all` 保存场景，返回 `saved: true`，场景 `isDirty: false`。
7. 重新读取场景层级，确认四阶段节点、环境、角色和粒子组件存在。
8. 通过 `editor_play` 进入 Play Mode，状态返回 `playing`。
9. 读取 Editor 状态后通过 `editor_stop` 退出，状态恢复 `ready/stopped`。
10. 通过 `unity projects verify` 检查项目，结果 `errors: 0, warnings: 0`。
