# EXP-2026-113 跨工程 VFX 摄入完整性门禁

## 目标

把跨 Unity 工程导入特效时最容易被人工漏检的三类问题变成可复用、可失败的摄入门禁：

```text
Prefab 引用 Material
  -> Material 的 m_Texture GUID 解析为真实 Texture
  -> Material GUID 无重复
  -> Shader CustomEditor 在目标工程有可用 Editor 类或明确人工处理
```

该门禁属于资产摄入与训练数据来源可信度，不替代 Unity Play Mode、WebGL 或人工视觉评价。

## 实现

实现入口：`workspace/tools/vfx_source_ingest.py`，版本 `vfx_source_ingest.v2`。

每次摄入额外写出 `ingest_integrity_report.json`，并在 `source_manifest.json` 的 `extraction` 中记录：

- `integrity_report_path`
- `material_integrity_gate`
- `shader_custom_editor_status_counts`
- `shader_gui_policy_path`
- `copy_shader_gui_dependencies`

### Material 门禁

解析 `.mat` YAML 中的 `m_Texture`：

- `resolved`：带 GUID 且在工程中解析为 Texture。
- `unbound`：`fileID: 0` 的合法空槽，不视为错误。
- `unity_builtin`：无 GUID 的 Unity 内置引用。
- `missing`：带 GUID 但不存在目标 Asset。
- `wrong_asset_type`：带 GUID 但解析到非 Texture。

`missing`、`wrong_asset_type` 或任意重复 Material GUID 会将 manifest 写为 `blocked` 并使摄入命令返回失败。检查范围不只限于选中的目录，还会追踪 Prefab 直接引用到的选区外 Material。

### ShaderGUI 门禁

扫描实际使用 Shader 的 `CustomEditor "<Class>"` 声明，报告：Shader 路径、类名、来源/目标可用性、包提供情况、许可证状态和复制动作。

默认不复制任何 Editor 脚本。只有策略文件同时声明 `allowed: true`、允许的 `license_status`、`source_path`、`target_path` 且路径均在对应项目 `Assets` 内时，`--copy-shader-gui-dependencies` 才能复制。未满足时记录 `needs_manual_dependency`，但不把 Inspector 依赖缺失误判成运行时材质缺失。

## 自动化验证

`workspace.tests.test_vfx_source_ingest` 共 16 项通过，其中新增：

- 未解析 `m_Texture` GUID 必须失败。
- 目标范围重复 Material GUID 必须失败。
- 选区外、由 Prefab 引用的 Material 仍进入 `m_Texture` 审计。
- 空 source path 必须失败，不能生成零资产假阳性。
- 显式许可策略可受控复制 `CustomEditor` 对应的目录，并回读为 `copied_allowed`。

## 真实样本：Fx_com_sheilder

输入 Prefab：

```text
UnityDemo/EffectDemo/Assets/VFXSourceIngest/Trains/Trains_FX_All_001/
ArtResources/FX/Battle/Fx_com_sheilder/Fx_com_sheilder.prefab
```

输出：`workspace/data/vfx_generation/sources/Trains_shield_001_integrity_r002/ingest_integrity_report.json`

结果：

- 3 个 Material。
- 36 个 `m_Texture` 槽：9 个 `resolved`，27 个合法 `unbound`。
- 0 个重复 Material GUID，Material gate `passed`。
- GUID 引用类型包含 material、texture、shader、mesh；工具同样可记录 script 类型。
- `ColorDefault.shader` 声明 `CustomEditor "LWGUI.LWGUI"`。
- `LWGUI.LWGUI` 在目标工程 `Assets/Editor/ThirdParty/LWGUI/LWGUI.cs` 可用，目标状态 `available`。

该样本证明材质、贴图、Shader、Mesh 和 Inspector ShaderGUI 的来源证据已被区分记录；它不替代该护盾的 Play Mode 渲染和人类风格标签。
