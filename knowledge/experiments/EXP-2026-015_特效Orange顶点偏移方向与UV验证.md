# EXP-2026-015：特效Orange顶点偏移方向与UV验证

## 目的

验证顶点偏移是否由法线、Noise/Mask、纹理寻址和 UV 组织共同决定，并确认分块模型、径向过渡和贴地边界的可迁移条件。

## 对照组

- `Vertex_A`：规则细分网格 + 单色权重，确认法线方向。
- `Vertex_B`：同一网格 + 循环 Noise + 单轴 UV 流动。
- `Vertex_C`：B + 中心白/边缘黑 Mask。
- `Vertex_D`：B + 反相 Mask，观察边缘运动/中心锁定。
- `Vertex_E`：UV 拉伸或错位的网格，作为位移破碎反例。
- `Vertex_F`：分块复制合并模型，比较深度写入开启/关闭及贴地边界。

## 固定变量

模型尺寸、顶点数量、摄像机、背景、灯光、材质混合模式、分辨率、播放时长和目标平台固定。每组只改变一个控制因素。

## 观察指标

- 位移方向是否与法线和预期轴向一致。
- 循环贴图是否连续流动，单向贴图是否在边界停止。
- Mask 反相后中心/边缘运动区域是否交换。
- 软硬参数改变时，出现/消失边界是否自然且无断裂。
- UV 拉伸是否造成左右破碎、纹理跳变或位移不连续。
- 分块模型是否穿插、抬升或产生错误深度；复制小光层是否独立可控。
- 网格顶点数、材质数量、透明过绘和帧时间。

## 通过标准

1. A 能稳定复现法线决定方向，且改变法线后方向可预测。
2. B 的循环流动连续，C/D 能分别得到中心动和边缘动。
3. E 明确显示 UV 混乱导致的破碎或不连续，说明 UV 是前置条件。
4. F 能记录深度写入和贴地边界的适用条件，不把“抬升”误判为通用效果。
5. 结果绑定 Unity 版本、渲染管线、网格细分、平台和录屏/截图证据。
