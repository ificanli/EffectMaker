# EXP-2026-019：特效Orange女娲一技能四向节奏与贴图分层验证

## 目的

验证四向复用、中心留白/边缘高亮、遮罩错时和快进慢出爆发是否提升技能可读性、层级和冲击力。

## 对照组

- `Nuwa1_A`：四向完全复制、同曲线、同速度、单一亮度层。
- `Nuwa1_B`：四向共享基础 UV，但分别调整角度、曲线、速度和拖尾。
- `Nuwa1_C`：B + 中心留白、宽边光/细亮边双层和冷暖分区。
- `Nuwa1_D`：C + 本体 Mask、Noise/额外 Mask 错时流动。
- `Nuwa1_E`：D + 闪光、方块、拖尾、扭曲、粒子分阶段快进慢出。
- `Nuwa1_F`：所有层同时出现、中心填满、ADD 过强的反例。

## 固定变量

摄像机、分辨率、背景、总时长、模型尺寸、主要色相和目标平台固定；记录 Unity 版本、渲染管线、材质数量、粒子数量、透明过绘和帧时间。

## 观察指标

- 四向是否仍属于同一主题，且不出现机械重复。
- 中心留白与边缘光是否提升轮廓阅读。
- 错时 Mask 是否比全层同步更自然。
- 快进慢出是否增强爆发冲击并保持收尾清晰。
- ADD 与透明叠加是否过曝，粒子和空间扭曲是否抢主体。

## 通过标准

1. B 比 A 更少出现重复感，四向动势仍统一。
2. C 比单层亮边更能读出轮廓与中心层级。
3. D/E 提升流动和爆发节奏，且不造成串层。
4. F 明确显示同步出现、中心填满或过曝的负面效果。
5. 结果绑定 Unity 录屏/截图和性能数据；无工程时保持 `planned`。

## 当前状态

`planned`。当前无可运行 Unity 工程，尚未执行；结论保持 `experimental`。
