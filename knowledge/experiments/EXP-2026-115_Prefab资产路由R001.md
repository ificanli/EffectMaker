# EXP-2026-115：Prefab 资产路由 R001

## 目标

为生成的 PrefabGraph 建立可追溯的 Material、Texture、Shader 和 Mesh 选择层，覆盖 billboard、mesh particle 和冲击贴花三类常用路径。资源选择必须基于 Unity 审计和内容标签，不能根据文件名猜测，也不能在缺资源时静默回退。

## 输入与验证

| 项目 | 证据 |
|---|---|
| Unity 工程 | `UnityDemo/EffectDemo`，Unity `2022.3.16f1c1` |
| 材质/Shader 审计 | `UnityDemo/EffectDemo/Library/VFXSourceIngest/material-binding-audit.json` |
| 纹理标签 | `workspace/data/vfx_generation/datasets/trains_fx_all_001/texture_tags.jsonl` |
| Mesh 几何审计 | `workspace/data/vfx_generation/generated/prefab_asset_routes_r001/mesh_audit.json` |
| 路由计划 | `workspace/data/vfx_generation/generated/prefab_asset_routes_r001/asset_route_plan.json` |
| 资产结果 | 材质记录 730/730 通过，FBX 几何记录 39/39 通过，UV 无效 0 |

Unity API 审计器 `EffectDemoAssetRouteAudit` 通过 `AssetDatabase.LoadAllAssetsAtPath` 读取 FBX 子 Mesh，检查顶点数、子网格数、UV 数量和 Bounds；材质通过 `AssetDatabase.LoadAssetAtPath<Material>` 检查 Shader 与 `_MainTex`。审计批次没有解析 Prefab YAML，也没有修改来源资源。

## 路由规则

| 路由 | 材质/纹理规则 | 几何与绑定规则 |
|---|---|---|
| `billboard` | 允许 Shader 且有 `_MainTex`；优先 `slot.emission_map` 或 `slot.alpha_mask` | 使用已有 ParticleSystemRenderer Billboard；记录真实 target component |
| `mesh_particle` | 同样通过 Shader 与纹理槽兼容检查 | 从已导入 FBX 选择 Mesh；要求 Unity local 轴向、来源 Pivot、UV 有效；没有 Mesh Renderer 的 Graph 必须创建显式新组件，不能回退到 Billboard |
| `impact_decal` | 优先 `role.impact_ring`、`semantic.ring` 或 `slot.alpha_mask` | 明确声明 quad 几何和 normal 对齐；不能把它当成普通 Billboard 的隐式替换 |

每条资产记录都保留 `asset_id`、工程相对路径、SHA-256、授权状态、Shader 名称、纹理标签、槽位角色和选择依据。材质当前标记 `local_source_unconfirmed`，纹理标记 `local_reference_only`；这不是公开分发授权结论。

## 实际结果

`asset_route_pfg_9faaa64da81c8c7665aa` 覆盖三类路由且计划状态为 `pass`：

- `billboard`：`Common/ColorDefault` + 带 `slot.alpha_mask|slot.emission_map` 的纹理，绑定现有 ParticleSystemRenderer。
- `mesh_particle`：`Common/ColorDefault` + 同类纹理 + `Mod_301_yuanhu_25d38846b4eecbc2.fbx`，Mesh 审计为 `unity_api_geometry_audit_pass`；当前 Graph 没有 Mesh Renderer，计划明确 `requires_component_creation=true`。
- `impact_decal`：`Common/ColorDefault` + 带 `slot.alpha_mask` 的环形纹理，几何为 quad，表面对齐为 normal。

## 结论与限制

资产路由已经从单一硬编码材质模板扩展为三类可复现选择计划，可以作为 Prompt Graph 生成后的 AssetPlan 输入。它证明的是路径、Shader 属性、纹理槽和 Mesh 几何兼容性，不证明三类路由已经在所有新 Prefab 中运行可见，也不代表视觉质量。下一步需要把该计划接入 Unity 编译器，生成真实三类 Prefab 并分别做 Play Mode/连续帧验证。
