# EXP-2026-020：特效Orange女娲二技能对流合体与路径生物验证

## 目的

验证中心向两侧的镜像 UV 对流、中心合体冲击、角点材质层级以及样条 IK 路径动画是否共同提升二技能的空间表达和可读性。

## 对照组

- `Nuwa2_A`：两个同向平面 + 直接缩放长方体 + 无中心转换。
- `Nuwa2_B`：单平面左右镜像 UV + Mask，形成中心向外对流。
- `Nuwa2_C`：B + UV 断开/修复拉伸 + 中心接触爆发分层。
- `Nuwa2_D`：C + 中部降噪/四角强化 + 收束流光。
- `Nuwa2_E`：独立长条模型 + 骨骼/蒙皮/样条 IK + 路径约束。
- `Nuwa2_F`：路径过近、过远、轴向错误或过强 Noise 的反例。

## 固定变量

摄像机、分辨率、背景、总时长、主体尺寸、颜色主题和目标平台固定；记录 Unity/建模软件版本、材质数量、粒子数量、透明过绘、骨骼数量和帧时间。

## 观察指标

- B 是否明确表现中心向两侧分流，而不是同向平移。
- C 是否减少长方体贴图拉伸并让碰撞力点可读。
- D 是否增强方块体积而不增加视觉噪声。
- E 是否让柔性模型沿路径平滑弯曲并与主体保持空间关系。
- F 是否暴露翻转、穿模、失去关联或对称结构破坏。

## 通过标准

1. B 比 A 更容易读出对流方向。
2. C/D 比直接缩放更少出现贴图拉伸，中心爆发更清晰。
3. E 的头部、尾部和路径弯曲连续，无明显翻转和穿插。
4. F 能复现路径距离、轴向或 Noise 失控的负面效果。
5. 结果绑定录屏/截图、版本和性能数据；当前无 Unity 工程，保持 `planned`。

## 当前状态

`planned`。尚未执行，结论保持 `experimental`。
