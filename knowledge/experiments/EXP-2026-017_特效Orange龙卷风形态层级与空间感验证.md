# EXP-2026-017：特效Orange龙卷风形态层级与空间感验证

## 目的

验证龙卷风的实体感、随机性和空间感是否来自 UV 形变、网格细分、软边/顶点偏移、多层错速和天空背景的组合。

## 对照组

- `Tornado_A`：单层圆柱/环形网格 + Size 缩放。
- `Tornado_B`：A + 环形 UV 流动/旋转。
- `Tornado_C`：B + 主体/边缘/中心三层，速度和方向略错开。
- `Tornado_D`：C + 软边溶解、局部顶点偏移和辅助光。
- `Tornado_E`：D + 天空/背景流动层。
- `Tornado_F`：过强旋转或全层同速的反例。

## 固定变量

摄像机、分辨率、播放时长、背景颜色、模型总体尺寸和目标平台固定；每组只改变一项。

## 观察指标

- 变胖/变窄/压扁是否能由 UV 形变复现，而不是仅靠 Size。
- 旋转强度是否增强实体感，何时开始暴露边缘。
- 多层错速是否比全层同速更自然，是否出现串层。
- 软边溶解和中段向两侧出现是否连续。
- 天空层对空间深度、上下运动参照和主体可读性的影响。
- 网格顶点数、材质数量、透明过绘和帧时间。

## 通过标准

1. B 比 A 更容易读出形态变化和卷曲感。
2. C/D 比单层版本更有实体层级，但轮廓仍清楚。
3. E 能明确提升空间感，且不抢主体。
4. F 明确显示过强旋转或同速叠加的负面效果。
5. 结果绑定 Unity 版本、渲染管线、平台和录屏/截图证据。

## 当前状态

`planned`。当前无可运行 Unity 工程，尚未执行；结论保持 `experimental`。
