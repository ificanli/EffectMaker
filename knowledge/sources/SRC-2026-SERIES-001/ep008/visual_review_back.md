# EP008 视觉核对：后段

## 覆盖范围

- 时间：`01:19:24–01:59:14`
- 案例：火焰过渡、分片纹理、吸收能量、火焰爆点、最终武器与收尾功能。
- 证据目录：`visual_check/09_fire_charge/`–`12_final_weapon/`

## 主要结论

### 1. 火焰材质需要高亮到暗色的连续过渡

火焰的亮度变化应从刺亮逐步落到暗色，不能爆白后直接黑掉。高亮核心、红色主体、暗部边缘和软化纹理共同保持火焰识别。

- 时间：`01:19:24–01:23:32`
- 支持等级：明确支持。

### 2. 短武器和鬼脸特效要匹配方向与文化语义

短刀、鬼脸或中国风造型不能用过快、过平的环绕线条。应根据武器长度和速度方向设计分段纹理、发射方向和拖尾，并参考同类题材的形体语言。

- 时间：`01:22:21–01:25:12`
- 支持等级：基本支持。

### 3. 复杂纹理应拆分为多个面片和慢速循环

一张贴图包裹全部范围会使动态僵硬、循环过快。可拆成两到四个面片，分别控制扭动、流速、透明度和循环周期；吸收效果要同时表现纹理流动与整体缩放。

- 时间：`01:25:12–01:35:55`
- 支持等级：明确支持。

### 4. 大型爆点要挡住主体并保留残留

大物体爆点应在瞬间覆盖一部分主体，之后用扩散、冰块或残流承接；切边过重、中心空洞和缺少后续残留会让爆炸显得轻飘。

- 时间：`01:36:14–01:38:18`
- 支持等级：明确支持。

### 5. 练习效果要优先做清楚动态，而不是只做颜色变化

颜色更换不能替代形体设计。应先确认发射器方向、溶解、纹理流动、扩散和收束，再用颜色区分属性。

- 时间：`01:30:24–01:35:55`
- 支持等级：明确支持。
