# EP005 视觉核对：中段

## 案例

### 4. 爆炸与冰块残留层次

- 时间：`00:26:00–00:34:03`
- 口述：颗粒、火星和爆炸中心不能被过长径向模糊吞掉；冰块、血花和地面残留不能全部同尺寸，必须有粗细、大小、明暗和消散先后；冲击方向要统一。
- 画面实际：问题帧中中心细节被白色模糊覆盖，地面冰块/残留形态重复；修改演示降低模糊、拉开尺寸差异，并保留中心血花和残留层。
- 动态前后差异：由整体白化、元素同质化转为中心可读、残留分层和受控变化。
- 支持等级：**明确支持**。
- 证据：`visual_check/04_explosion_layers/`、`visual/00-26-13.jpg`、`visual/00-32-47.jpg`。
- 限制：修改前后有暂停和 PS 操作切换。

### 5. 召唤魔王：视角与主体关联

- 时间：`00:34:03–00:42:03`
- 口述：召唤物出现后不能让地面法阵消失；镜头至少保持约25度俯视以读出地面；新出现的心力特效、刀光和人物影子应保持深红主色与共性；不要用纯 ADD 白光把人物和地面全部冲掉；画面构图中间不要出现像把人物劈开的硬线。
- 画面实际：低角度视角使法阵和地面承接消失，白色光晕压平人物/武器层；调整俯视和深红暗部后，人物、法阵和能量关系更清楚。
- 动态前后差异：由视角/颜色断裂和中心过曝转为地面可见、主色统一、人物主体保留。
- 支持等级：**明确支持**。
- 证据：`visual_check/05_king_summon/`、`visual/00-32-47.jpg`、`visual/00-39-20.jpg`。
- 限制：具体镜头角度为建议值，不是工程强制参数。

### 6. 176号：科技爆炸与薄膜干涉纹理

- 时间：`00:46:02–00:54:02`
- 口述：人物穿过科技装置后爆炸，中间不能空；加入薄膜干涉、空气质感和环状纹理能提升科技质感；范围填充应留出进入感；地面碎片更适合在区域内横向散落，不要全部向天飞。
- 画面实际：问题帧中心过空，圆环与爆炸边缘断裂；参考与修改示范增加中间纹理、薄膜色带和区域填充，爆炸空间更完整。
- 动态前后差异：由空心圆环、碎片垂直飞散转为中心有介质、环与爆炸连续、碎片服从区域方向。
- 支持等级：**明确支持**。
- 证据：`visual_check/06_176_tech/`、`visual/00-45-54.jpg`、`visual/00-52-27.jpg`。
- 限制：薄膜干涉为参考示例，未确认最终学员工程实现。

### 7. 284号：展示型法器与玩家使用态

- 时间：`00:52:01–00:58:03`
- 口述：展示型法器可以有更强的环绕、向上气流和地面扩散；玩家已拿到手的使用态则要减弱环境特效，避免抢主体；特效纹理不能压过模型本身。
- 画面实际：同一法器在展示场景中周围能量更丰富，使用态中人物/模型需要保持读图优先；修改方向是降低包裹特效或把螺旋气流做得更有方向。
- 动态前后差异：由展示与战斗使用混用转为按交互语境区分强度。
- 支持等级：**基本支持**。
- 证据：`visual_check/07_284_artifact/`、`visual/00-52-27.jpg`、`visual/00-59-01.jpg`。
- 限制：视频以语义对比为主，未提供同一镜头的完整 A/B 成片。
