# BV1AYonB6EYR：Unity顶点偏移详解 00:00–20:00 分段记录

## 原理

- 顶点偏移不是“给噪声图就会浮动”，核心是把顶点沿法线方向位移；法线朝向决定位移方向。
- 黑白/噪声贴图作为位移权重：黑色区域不动，白色区域移动；纹理越密，起伏点越多，纹理越少，起伏越少。
- 改变法线朝向可以把同一模型做成向上、向下或左右不同方向的起伏。上半部分朝上、下半部分朝下时，可形成中间隆起或对称变形。

## 制作步骤

1. 创建基础片/方块，整理坐标轴和法线方向，导入 Unity 后用 Mesh/材质验证位移方向。
2. 使用噪声贴图、Mask 和顶点偏移强度观察白色区域的移动，先确认方向，再调强度和流动。
3. 需要规则形态时，保持复制间距与角度一致；复制后合并为整体，第一步检查法线是否出现翻转或漏面。
4. 需要局部圆形/环形造型时，可将元素分离、删除不需要的部分，并重新归零局部坐标。
5. UV 需要规则铺排和对齐。直接挤压/缩放导致 UV 混乱，会使位移在两侧破碎；先整理 UV 再进入 Shader/材质位移。

## 限制

具体节点、工具名称和数值存在 Whisper 识别误差；Unity 版本、渲染管线、顶点密度和平台预算未确认。结论保持 `experimental`。
