# BV1zH4y1Q7bY：龙卷风质感制作 00:00–10:00

## 证据摘要

- 00:00–02:30：本集针对上一期龙卷风效果的质感问题进行拆解，先明确镜头、主体和转场结构。
- 02:30–04:25：星形/亮片不是静态叠图，而是通过环形模型上的 UV 运动产生变胖、变窄、压扁、出现和回收；只改 Size 无法得到同样的形态变化。
- 04:25–07:00：在图像工具中用参考线、擦除、拼接和复制制作可循环素材，先快速找大形，不追求一次画准。
- 07:00–10:00：把素材导入粒子/特效工具，使用一次播放而非循环，调整模型方向、单向 Mask、边缘软化和 Size，形成由小到大再收缩的节奏。

## 可执行结论

1. 先定镜头角度，再决定模型是否需要露底或处理背面。
2. 环形/圆柱模型配合极坐标贴图和 UV 运动，适合做星芒、卷风边缘等非线性形态。
3. 单纯 Size 只能缩放，不能替代 UV 形变、旋转和局部遮罩。
4. 素材草稿先保证大形、平行关系和可拼接性，再做细节。
5. 需要一次性出现/消失时关闭循环，避免素材重复滚动。
