# SRC-2026-001 第一集视觉核对记录

## 说明

本记录将语音转写与实际视频画面对齐。字幕只用于定位，结论以视频帧、连续动态和口述/画面对照为准。

## 前段核对范围

### 1. 打击造型与闪电衰减

- 时间：`00:00:39.770–00:04:02.100`
- 作者口述：打击造型前宽后窄、前亮后暗；闪电由高频、多股、强力逐步衰减为少量、短细的残留；打击点应有电火花。
- 画面实际：主体打击/刀光与闪电叠加；前段体量、亮度和线条密度更强，后段残留变细、变短、变少；打击点可见局部放射/花状闪电，但整体仍较依赖直线速度线。
- 结论：**基本支持**。
- 证据：`knowledge/sources/SRC-2026-001/visual_check/01_strike_lightning/`
- 限制：区间包含暂停、回放和案例切换，同一动作的连续边界存在少量不确定。

### 2. 旋转攻击 / 大风车

- 时间：`00:04:41.320–00:09:29.580`
- 作者口述：旋转攻击应照顾 360°，刀光和闪电应表现旋转、甩出和方向引导，副本要有粗细、长短和数量变化。
- 画面实际：可见旋转型刀光和闪电条带；后段加入外甩线条、点状火花和方向性闪电后，旋转暗示增强，但正面和上方仍明显强于侧后方，观众不能始终读出完整全向覆盖。
- 结论：**部分支持，核心问题成立**。
- 证据：`knowledge/sources/SRC-2026-001/visual_check/02_rotate_attack/`
- 限制：单一二维镜头不能证明角色背面没有三维布置；结论针对观众读图，不是对粒子系统实际空间布置的断言。

### 3. 爆炸中心与爆炸层次

- 时间：`00:09:29.580–00:12:07.440`
- 作者口述：爆炸中心为空，火焰、冰霜、闪电等属性都需要明确核心、体积、层次和力量感。
- 画面实际：外围闪光、烟尘/能量和散射元素较多，中心相对空，视觉重量集中在外围；爆发更像元素散开，而不是从强核心向外释放。
- 结论：**明确支持**。
- 证据：`knowledge/sources/SRC-2026-001/visual_check/03_explosion_core/`
- 限制：部分峰值来自暂停或回放，前后未必是同一次连续播放，但“中心空、外围多”在多个时点重复出现。

### 4. 水属性与冰属性

- 时间：`00:12:07.440–00:20:40.980`
- 作者口述：当前更像水；水应有水花、泡沫、含气感、速度感和统一的地面属性；降低核心、改变边缘和层次后才更接近冰。
- 画面实际：主体蓝/青色，部分高光和边缘较硬；整体首先读成半透明流动水体，不是明确冰块。转向冰处理时，形体更凝固、边缘更硬、核心更集中。差异来自透明度、硬边、核心和形体稳定性，不是单纯换色。
- 结论：**基本支持**。
- 证据：`knowledge/sources/SRC-2026-001/visual_check/04_water_ice/`
- 限制：案例群包含多次暂停和参数调整，水花、泡沫和地面元素的统一程度需要后续工程实验验证。

### 5. 火焰的实虚关系

- 时间：`00:20:40.980–00:21:55.220`
- 作者口述：火焰过于透明，缺少实心部分；头部过硬，不像自然燃烧，应降低硬度/核心强度并形成更自然的包裹。
- 画面实际：火焰以透明/半透明片状元素为主，实心暗部或高密度燃烧核心不明显；头部轮廓偏硬，像固定切片或硬壳。后段柔化和包裹有所改善，但没有完全建立实虚对比和体积核心。
- 结论：**明确支持**。
- 证据：`knowledge/sources/SRC-2026-001/visual_check/05_fire/`
- 限制：区间末尾接近视频案例边界，后续调整未纳入。

## 前段可沉淀规则

1. 能量衰减应同时改变数量、长度、粗细、频率和亮度，不能只做 Alpha 淡出。
2. “旋转攻击”必须让目标镜头中的观众读出攻击覆盖范围；360° 是玩法语义，不是单纯的几何布置。
3. 爆炸的外围细节不能替代核心体积；中心空会让爆发变成散点堆积。
4. 水和冰的区分依赖动态、硬边、透明度、核心和附属元素，不应只换色。
5. 半透明火焰需要实心/高密度部分提供视觉重心，轮廓还要避免固定尖硬的切片感。
