# Reports

本目录保存生成式特效试点的阶段报告和模型评估摘要。

## 当前报告

- `plugin_installation_plan.md`：AI 式 VFX 生成辅助插件调研、安装顺序、已安装清单、暂缓项和使用规则。
- `github_vfx_reference_snapshot_2026-08-28.json`：公开 GitHub 页面核验的 Unity VFX/URP/Shader 参考仓库星标、许可证、归档状态与采用边界快照。

报告应回答：

- 本轮生成了多少候选。
- 哪些候选被接受、部分接受或拒绝。
- 主要失败原因是什么。
- 下一轮采样策略如何变化。
- 是否形成了可训练样本。
- 是否足以进入下一层制作。

报告不能把候选通过、Unity 命令成功或截图存在写成最终视觉成功。
