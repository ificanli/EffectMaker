# VFX 生成训练课程

本目录把训练计划从单个刀光主体弧扩展为完整 VFX 生产能力训练。

核心原则：

- 先训练通用能力底座，再训练特效族适配器。
- 刀光主体弧只是第一个 curriculum 单元，不代表所有特效。
- 每个特效族都有不同拓扑、生成器和失败模式，不能用同一套弧线标准评价所有效果。
- 训练对象优先是 Unity 可编辑结构、参数和偏好判断，不是单张像素图。

## 通用能力底座

这些能力跨特效类型共享：

- 读图：主体能否被一眼读出。
- 形体：主形状是否支持技能意图。
- 层级：Core、Support、Accent、Residual 等层是否分工明确。
- 节奏：起势、峰值、持续、收束是否有过程。
- 材质：亮度、透明、噪声、溶解、UV 流动是否可信。
- 空间：是否和角色、地面、目标、镜头建立关系。
- 约束：粒子量、Overdraw、Shader 成本和目标平台限制。

## 特效族适配器

每个特效族负责自己的拓扑空间和专用评价。

| 特效族 | 典型拓扑 | 专用训练重点 |
|---|---|---|
| `slash` | 弧线、刃带、残影、命中碎片 | 锋利度、攻击方向、宽窄变化、主体/残留分离 |
| `fire` | 火舌、团块、烟火、火星、热扰动 | 翻腾、根部亮度、边缘破碎、烟火分层 |
| `lightning` | 主路径、分叉、跳闪、接触点 | 分叉节奏、瞬时高亮、路径可读、随机性控制 |
| `shield` | 球面、环、六边形/符号、碰撞波 | 包裹感、受击反馈、透明排序、边缘能量 |
| `smoke` | 软粒子、体积团、卷动、消散 | 体积感、软边、上升/扩散、遮挡和透明成本 |
| `explosion` | 核心亮爆、冲击波、碎片、烟火残留 | 冲击峰值、内外层次、残留方向、尺度 |
| `magic_circle` | 圆环、符文、旋转层、预警范围 | 图案密度、显隐节奏、层级清晰、地面贴合 |
| `water` | 水柱、水刃、浪花、涟漪、拖尾 | 流向、透明层、泡沫边缘、重力和回落 |

## 课程顺序

1. `SlashArc-Pref-001`：刀光主体弧候选搜索。
2. `LayerRole-Pref-001`：Core / Support / Accent / Residual 层职责判断。
3. `FireShape-Pref-001`：火焰团块与边缘破碎候选搜索。
4. `LightningPath-Pref-001`：雷电主路径和分叉候选搜索。
5. `ShieldImpact-Pref-001`：护盾包裹和受击反馈候选搜索。
6. `MaterialMask-Pref-001`：Mask、Dissolve、Flow、Shard 贴图生成与筛选。
7. `Timing-Pref-001`：起势、峰值、残留和消散曲线训练。

## 数据迁移规则

可以跨类型共享：

- 主体是否可读。
- 层级是否抢戏。
- 峰值是否明确。
- 收束是否拖沓。
- 材质是否有明显贴片、硬边或排序问题。
- 性能是否超预算。

不能直接跨类型共享：

- 刀光锋利度不能评价烟雾。
- 火焰翻腾不能评价护盾。
- 雷电分叉不能评价法阵。
- 水体流向不能评价爆炸碎片。

跨类型模型只能学习通用失败模式；类型适配器负责专用视觉语言。
