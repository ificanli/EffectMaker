01 / ONE SENTENCE

先记住一句话

当前还不是 Prompt 驱动的正式生成模型。 现有族生成器主要是固定拓扑、固定资产和窄参数采样；局部 Teacher 只能当约束和排序信号，不能把一批整体不合格的候选变成合格成品。当前主线是补齐通用 ProposalPlan、资产能力检索、Shader/顶点流执行契约和整体质量否决门。

旧方式

在一个场景里反复改颜色、尺寸、生命周期和偏移。每次只看一个版本，很难知道到底是哪一个变化带来了改善，也容易把失败基础继续修补下去。

新方式

把每个版本保存为候选规格和 seed。候选之间可以横向比较，人工意见可以被记录，下一轮可以继承“为什么保留/为什么拒绝”。

07 / RESPONSIBILITY

层级为什么要分职责

层不是“多加几层就更丰富”。每一层都应该有关闭后可预期的变化。

core

主体

负责一眼能读出的核心意图。刀光可以是弧，护盾可以是壳，爆炸可以是体积，不能把“主体”固定成一种形状。

关闭后：技能主要意图应消失。
support

支撑 / 氛围

负责空气感、包围感、流动、尺度和空间关系，不应复制主体成为职责相同的第二层。

关闭后：主体仍应独立可读。
hit

命中强调

负责短时局部爆发、尖刺、碎片、冲击环或接触点，位置和寿命必须服务动作。

关闭后：主体结构不应被破坏。
residual

收束残留

负责峰值后的方向性余韵，通常更碎、更淡、更短，不是把整条主体延长显示。

关闭后：节奏仍应有收束。

08 / GATES

哪些事情机器做，哪些必须人做

自动评价的边界很重要：它负责节省复看时间，不负责替你宣布“好看”。

环节机器可以做机器不能可靠替代
硬过滤检查文件、时间点、场景/相机、Console、可见面积、过曝、帧间变化。判断刀尖是否有审美力度、形体是否像参考。
类型评分按特效族读取对应参数，例如刀光看方向，火焰看根部，护盾看包围关系，材质轨迹看状态信号。从参数准确推断最终审美效果；规格和执行分数都只是可解释证据。
语义人工分开保存特效元素、特效类型和播放状态。把火焰/冰霜与刀光/法阵混在一个枚举，或填写审美分数。
专业 Teacher从专家原话、时间码、前后对比和 Unity 复刻生成审美监督。把字幕关键词或知名来源直接当高质量标签。
视觉验收提供可追溯的参考图、候选图和前后对比。在没有实际图像输入时声称“效果更好”。
硬过滤：比如没有截图、Unity 有错误、主体完全不可见，机器可以直接拒绝；但“这条弧线不够像参考”仍然要由人看图判断。

09 / TRANSFER BOUNDARY

跨特效共享流程，不共享未经验证的审美

刀光、火、雷和护盾复用相同的证据管线，但每个族仍要通过专业资料和 Unity 复刻独立证明主体、节奏、材质和偏好。

可共享的底座

  • 资产闭包、m_Texture 与 Material GUID 门禁
  • Prefab/Particle/Renderer 结构、时间采样与资源审计
  • 空帧、上下文依赖、固定镜头主体过小等技术路由
  • Prompt、seed、VFXSpec、候选回放和反馈追溯格式

必须由目标族重学

  • Slash 的弧线与命中切面
  • Fire 的体积、热扰动与上升流
  • Lightning 的分叉、跳点与脉冲
  • Shield 的曲面覆盖、受击涟漪与防护反馈
迁移门槛：目标族先通过资产闭包、独立/上下文技术路由和真实回放；之后同 Prompt 生成 4 到 8 个同族候选，由专业 Teacher 或专家对照提供目标族偏好。Slash 的“好看”不能替代 Fire、Lightning 或 Shield 的“好看”。

10 / NEXT ACTION

接下来应该发生什么

已有 Prefab、Material、Teacher 和窄轴模型都作为底层数据与约束保留。主线先把 Prompt 转成可学习、可检索、可执行的 ProposalPlan，再由 Unity 执行和整体质量门判定是进入正样本还是负样本。

将制作教程转为 ProcedureSpec抽取有序步骤、层职责、Shader/贴图功能、参数范围、失败修正和验证证据；在目标 Unity 工程复现后才升级为 Planner 训练监督。
完成通用 ProposalPlan合并 Prompt、ProcedureSpec 与 Prefab 结构先验，输出 TopologyPlan、ShaderPlan、TexturePlan、ParameterPlan 和 TimingPlan；各族只提供可插拔操作子。
补齐资产与执行契约Material/Shader/Texture/Mesh 必须按层职责联合检索；Particle vertex streams、Shader properties/keywords、MPB 和材质动态参数必须进入 PrefabGraph 编译与回读。
将已验证材质配方接入正常生成入口独立颜色与Fixed机制已验证；把包内URP Shader、模板状态、贴图通道和顶点流配方交给正常MaterialPlan检索。校准示例仍是明确实验选材，不能冒充自动排序已正确。
建立整体绝对质量门局部 Teacher 可以排序同轴候选，但不能直接批准成品。一批候选全部不合格时必须全部拒绝，不强行选 Top-1。
定义失败分流普通质量失败进训练负例；动作空间缺失才扩展操作子；Shader/顶点流等执行缺失修执行器；不再按每个测试手工改架构。
