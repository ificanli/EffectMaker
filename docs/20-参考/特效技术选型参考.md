# 特效技术选型参考

| 视觉需求 | 优先技术 | 适用说明 |
|---|---|---|
| 少量火花、简单烟雾、UI 特效 | Particle System | 参数直观，适合数量可控的通用效果 |
| 大量粒子、GPU 模拟、复杂粒子行为 | VFX Graph | 适合高数量和复杂更新逻辑 |
| 刀光、冲击波、能量环 | Mesh + Shader | 形状稳定，轮廓和材质更容易控制 |
| 激光、路径、稳定拖尾 | Trail Renderer 或带状网格 | 适合连续轨迹和方向性效果 |
| 溶解、流动、扭曲、边缘光 | Shader Graph / HLSL | 通过纹理、噪声和深度实现表面变化 |
| 多阶段技能演出 | Timeline + 预制体 | 明确控制前摇、爆发、持续和收尾 |
| 角色挂点和命中触发 | Prefab + 脚本事件 | 适合技能系统和角色动画集成 |
| 全屏闪白、冲击和屏幕扭曲 | Volume / 后处理 | 影响摄像机画面，需控制持续时间和强度 |

## 选型原则

1. 先根据视觉现象选技术，再根据项目限制调整。
2. 稳定、可控的轮廓优先使用 Mesh 和 Shader。
3. 大量、随机、动态的细节优先使用粒子或 VFX Graph。
4. 需要与角色动作同步时，优先考虑预制体和事件接口。
5. 不要用复杂系统解决简单效果，也不要用大量粒子掩盖缺少形状的问题。
6. 目标平台较弱时，优先减少透明叠加、后处理和高成本 Shader。

## 组合建议

完整技能通常由多种技术组合：

- 核心形状：Mesh + Shader。
- 动态细节：Particle System 或 VFX Graph。
- 轨迹和方向：Trail 或带状网格。
- 地面反馈：投影网格、Decal 或粒子。
- 镜头反馈：Volume、后处理和摄像机脚本。
- 时间编排：Timeline、动画事件或技能事件系统。

## 选型记录格式

每个特效必须记录：

- 视觉目标。
- 采用的技术。
- 放弃的候选技术。
- 选择原因。
- 已知限制。
- 后续替换成本。
