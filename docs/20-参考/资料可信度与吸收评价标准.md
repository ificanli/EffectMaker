# 资料可信度与吸收评价标准

本标准评价的是资料能否支持可靠学习和复用，不评价最终特效的美术质量。视觉质量仍使用现有的[质量评价标准](质量评价标准.md)。

## 评价维度

每项使用 0 到 3 分：

- 0：没有信息或无法判断。
- 1：信息有限，风险较高。
- 2：基本充分，可在限定条件下使用。
- 3：证据完整，适合复现和迁移。

| 维度 | 评价问题 |
|---|---|
| 来源可靠性 | 作者、平台和原始出处是否清楚？是否为官方或原作者发布？ |
| 证据完整性 | 结论能否定位到章节、时间戳、文件路径、参数或实验数据？ |
| 可复现性 | 是否提供了足够的步骤、资源、版本和依赖？ |
| 版本适配性 | Unity、渲染管线、插件和目标平台是否明确？与当前环境差异多大？ |
| 限制说明 | 是否说明不适用场景、性能代价和已知问题？ |
| 可迁移性 | 结论能否抽象成其他效果也适用的原则或模块？ |

## 状态门槛

- **已筛选**：来源可靠性和授权信息不为 0，基本元数据完整。
- **已提取**：至少有一条可定位证据和一份结构化摘要。
- **实验中**：已经定义最小验证问题、环境和通过标准。
- **已验证**：关键结论在目标环境中成功复现，或失败原因已经被定位。
- **已吸收**：验证结果已经进入知识卡片、教程、规范、效果或资产，并建立追踪链接。
- **已归档**：保留用于追溯，但当前不作为优先依据。
- **已废弃**：版本过期、来源失效、无法复现或被更可靠资料替代。

## 吸收最低标准

“看过”不代表“吸收”。一份资料要进入 `已吸收`，至少需要：

1. 有来源、授权、版本和适用范围记录。
2. 有可以定位的事实证据。
3. 有知识卡片，区分事实、推断和未解决问题。
4. 有一个最小 Unity/MCP 实验，或者明确记录无法验证的原因。
5. 有实验结果和限制说明。
6. 已关联到至少一项规范、教程、效果记录或可复用资产。

## 降级规则

出现以下情况时不得直接采纳为稳定结论：

- 来源无法追溯或授权不明。
- 只有最终效果，没有步骤和参数。
- 版本和渲染管线不明。
- 作者把个人偏好表述为普遍规则，但没有证据。
- 实验无法复现且没有记录失败原因。
- 资料内容与当前 Unity 版本存在未评估的关键差异。

## 复核规则

被 Unity、渲染管线或插件版本影响的卡片，需要在环境发生重大变化时重新验证。长期未使用的卡片至少每年检查一次来源、链接、版本和适用性。
