# 资料分类与术语规范

## 资料 ID

使用稳定 ID，不使用“最新”“最终版”等不稳定名称：

- `SRC-YYYY-NNN`：原始资料。
- `CARD-YYYY-NNN`：知识卡片。
- `EXP-YYYY-NNN`：验证实验。
- `FX-YYYY-NNN`：具体特效记录。
- `AST-YYYY-NNN`：共享资产记录。
- `TASK-YYYY-NNN`：一次投喂任务。

年份使用资料首次登记年份，编号在同类对象中递增。

## 资料类型

- `source-file`：Unity 工程、Prefab、UnityPackage、Shader、VFX Graph、脚本或其他源文件。
- `video`：教学视频、演示视频、会议记录或录屏。
- `article`：博客、教程、制作文章或技术分析。
- `official-doc`：Unity、渲染管线、插件或工具的官方文档。
- `paper`：论文、技术报告或研究资料。
- `image`：参考图、分解图或图集。
- `project`：可运行的示例项目或公开仓库。
- `search`：自主检索得到的资料集合或检索记录。

## 必填元数据

每份资料至少记录：

- 资料 ID 和标题。
- 类型、主题标签和关联效果 ID。
- 原始 URL 或本地来源路径。
- 作者、平台和发布日期（未知时明确写“未知”）。
- 获取日期。
- 授权状态和使用限制。
- Unity 版本、渲染管线、目标平台（适用时）。
- 当前状态和最后复核日期。

## 推荐标签

### 视觉标签

`火焰`、`烟雾`、`能量`、`爆炸`、`雷电`、`冰霜`、`刀光`、`拖尾`、`冲击波`、`溶解`、`扭曲`、`地面反馈`、`后处理`。

### 技术标签

`Particle System`、`VFX Graph`、`Shader Graph`、`HLSL`、`Mesh`、`Trail`、`Timeline`、`Prefab`、`Decal`、`Volume`、`MCP`、`Overdraw`。

### 状态标签

`待筛选`、`已筛选`、`已提取`、`实验中`、`已验证`、`已吸收`、`已归档`、`已废弃`。

## 术语规则

- 首次出现的英文技术名词保留英文，并可附中文解释。
- 沿用项目已有的视觉拆解维度：形状、运动、材质、颜色、节奏、空间层次、环境交互、性能。
- `资料`指原始输入，`知识卡片`指提炼结果，`实验`指验证行为，`资产`指 Unity 中可复用的资源，不能混用。
- `参考`不等于`证据`；只有可以定位和复查的内容才标记为证据。

## 文件命名

推荐格式：

```text
SRC-2026-001_标题.md
CARD-2026-001_主题.md
EXP-2026-001_验证目标.md
TASK-2026-001_问题.md
```

文件名使用简短中文或 ASCII 描述，避免包含不可移植的特殊符号。
