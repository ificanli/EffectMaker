# VFX.library 视觉参考媒体入库设计

## 目标

将 `E:/BaiduNetdiskDownload/VFX.library` 登记为一个可追溯的内部视觉参考来源，建立 GIF/视频媒体的只读索引、元数据、内容去重和证据入口，为后续视觉聚类、审美/制作知识卡片与 Unity 验证提供可靠输入。

## 范围

本阶段处理来源登记、媒体扫描、媒体元数据、内容哈希、规范化名称重复关系、代表帧/海报入口和质量报告。不复制、移动、改名或修改原始素材，不把外部媒体直接当作可分发 Unity 资产。

后续阶段再处理视觉主题聚类、AESTHETIC/CRAFT 卡片和 EXP 验证。

## 架构

知识来源记录位于 `knowledge/sources/SRC-2026-VFXLIB-001/`，负责来源、授权、状态和证据追踪。媒体索引位于 `workspace/data/resource_index/vfx_library/`，负责扫描清单、哈希、元数据、重复组和扫描摘要。索引通过 `source_id` 与知识来源关联，但不替代来源记录。

现有 `workspace/tools/media.py` 的 ffprobe/ffmpeg 能力优先复用；GIF 作为动画媒体处理，保存帧数、循环/时长等字段，视频保存时长、FPS、分辨率和帧数。代表帧用于视觉检索，时间序列证据保持独立。

## 证据与状态

来源初始状态为 `screened`，扫描条目记录 `screened` 或 `needs_review`。损坏、未完成下载、无法探测或授权不明的条目不得进入已吸收知识。任何审美结论必须回溯到 `media_id`、文件路径和帧/时间点。

## 限制

本地副本仅用于工程内部学习、检索和分析。作者、平台、原始 URL 和授权状态无法从本地证据确认时标记为 `unknown`，不得猜写。所有扫描工具必须只读访问输入目录，并支持重复运行而不改变输入。
