# 换电脑恢复工程与本地资料

本次迁移由 Git 仓库和 GitHub Release 两部分组成。只克隆仓库不能恢复下载媒体、原始素材、模型权重和实验截图。

## 迁移完成状态

迁移资料正在上传。只有 Release 中出现 `recovery-manifest.json`，并且 Release 说明标记所有分组上传和校验完成后，才能据此删除旧电脑上的项目。

- 工程仓库：<https://github.com/ificanli/EffectMaker>
- 迁移资料：<https://github.com/ificanli/EffectMaker/releases/tag/recovery-2026-10-12>
- 日期：2026-10-12。

## 恢复工程文件

安装 Git、Python 3.10 或更高版本，然后克隆仓库。路径可以自行选择。

```powershell
git clone https://github.com/ificanli/EffectMaker.git E:\Unity特效人工智能学习
```

工程模型、音效及本地包源码存放在 Git 中。大批本地资料存放在 Release 分卷附件中，每卷有 SHA-256 校验值，每个恢复文件也有独立校验值。

## 恢复本地资料

先准备足够的空间。完整恢复需要同时容纳分卷下载文件和解压文件。下载文件默认存放在新克隆目录的 `.git/recovery-downloads/` 中，校验通过的分卷在再次运行时会复用。

```powershell
python E:\Unity特效人工智能学习\workspace\tools\restore_remote_recovery.py --project E:\Unity特效人工智能学习
```

恢复脚本会检查下载分卷的 SHA-256，再解压并检查每个文件。目标目录存在不同内容时会停止；核实后才使用 `--overwrite`。

如果暂时只需要某类资料，使用 `--groups` 指定分组：

```powershell
python E:\Unity特效人工智能学习\workspace\tools\restore_remote_recovery.py --project E:\Unity特效人工智能学习 --groups beads unity-local-assets
```

| 分组 | 内容 |
|---|---|
| `beads` | 任务数据库原生快照和任务全量 JSONL 导出 |
| `raw-resources` | `resource/` 原始素材 |
| `learning-media` | 教程视频、音频及其他本地来源资料 |
| `experiments-and-models` | 实验帧、逐帧材质明细、训练模型和数据 |
| `unity-experiment-projects` | 实验用 Unity 工程副本的源文件，不含 Library |
| `unity-local-assets` | 安装包及本地导入源资源 |
| `local-support-files` | 其他非凭据辅助资料与本地结果 |

## 恢复 Beads 任务库

先恢复 `beads` 分组，再安装兼容的 Beads CLI。原生快照恢复的是数据库、历史和工作集；JSONL 是额外的互操作导出。

```powershell
Set-Location E:\Unity特效人工智能学习
bd init --prefix vfx --non-interactive
bd backup restore E:\Unity特效人工智能学习\_migration\beads-native --force
bd list --all
bd memories
```

`--force` 会替换目标任务数据库。只在新电脑的新克隆中执行，已有任务库时先核实目标路径。

## 打开 Unity

- 正式工程：`UnityDemo/EffectDemo6.0/`，Unity `6000.5.9f1`。
- 兼容工程：`UnityDemo/EffectDemo/`，Unity `2022.3.62f3c1`。

使用 Unity Hub 安装对应 Editor 和需要的构建模块。恢复 `unity-local-assets` 后再打开兼容工程。Unity 会重新生成 Library；首次导入需要等待。

若在其他盘符恢复，脚本和历史实验配置中的绝对路径可能需要调整。迁移保存文件内容，不自动安装系统工具、Unity Editor、GPU 驱动或 Python 依赖。

## 不包含的内容

迁移排除 Git 对象缓存、Unity Library/Temp、Python 环境与缓存、可重建资源索引和向量缓存，以及本地凭据。具体文件排除理由保存在 Release 的 `recovery-manifest.json` 中。

账号登录、API Key、SSH 私钥和其他凭据应在新电脑重新配置，不从公开仓库恢复。安装依赖时参考 `requirements-media.txt` 和 `requirements-training.txt`。

## 删除旧目录前

确认所有分卷下载校验通过、所有需要的分组恢复成功、Beads 任务可读取，并在新电脑打开目标 Unity 工程。Git 推送成功或工作区干净不能替代这些检查。
