# 特效迭代方法

## 先建立基准

每次迭代前保存当前版本，并记录以下信息：

- 当前版本号。
- 修改目标。
- 测试场景和镜头位置。
- 观察时间点。
- 当前主要问题。

## 问题分类

将问题归入一个主要类别：

- 读图：主体不清楚、轮廓不明确、规模难判断。
- 节奏：爆发点不突出、持续过长、收尾拖沓。
- 材质：透明度、流动、噪声或高光不符合预期。
- 层次：核心、主体、细节同时出现，缺少空间关系。
- 融合：与地面、角色、灯光或镜头脱节。
- 性能：粒子、Overdraw、Shader 或后处理成本过高。

## 修改顺序

1. 先修正轮廓和主体规模。
2. 再修正运动和时间节奏。
3. 再修正颜色、材质和亮度层级。
4. 再加入环境交互和镜头反馈。
5. 最后处理细节丰富度和性能优化。

## 单变量迭代

每轮只改变一组相关参数。例如只调整爆发速度和生命周期，不同时改变颜色、噪声、粒子数量和材质。这样才能判断结果来源。

## 对比方式

使用相同镜头、相同时间点和相同曝光进行前后对比。动态特效至少检查前摇、爆发峰值、持续中段和收尾四个时间点。

## 停止条件

满足以下条件后可结束当前迭代：

- 主要视觉问题已经消除。
- 目标镜头下主体始终可读。
- 没有明显穿帮、闪烁或透明排序问题。
- 性能符合当前平台预算。
- 参数和资源已整理并完成复盘。
