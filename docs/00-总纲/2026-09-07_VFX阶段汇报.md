## 本阶段进展

1. 修复 Prompt 到执行字段的断链。真实 URP 下四组固定资产、固定 seed 对照完成 4/4 编译和回读，218 有效帧；颜色、方向和明确时长影响实际画面。这仍是规则化控制，不是训练出的通用 Planner。
2. 修复重复颜色乘法。灰色输入 0.5 先前被乘成 0.125，独立通道后保留 0.5；前景 R 均值从 23 变为 124。11/11 编译和回读、446 有效 URP 帧。
3. 核对教程，区分 Photoshop 操作、Unity 对象及贴图通道；明确黑色形体不等于透明消失。源视频不确定值和工程参数假设继续分开保存。
4. 定位批处理环境缺失 `ALLUSERSPROFILE`，恢复 UPM 与真实 URP。管线不匹配即使 PNG 有效也不放行正向训练。
5. 形成 0.3 秒蓝白闪电局部案例。R003 三种机制对照通过 3/3 编译、回读和 123 帧校验。R002 Fixed 源重建 41 帧逐像素一致；Blend 原样重拍仍有波动，未放行为完全一致。

此前最终工程验收记录为 555 项 Python 测试通过、两个工程 CLI 结构检查均 0 错误和 0 警告。它们是工程验收，不是成品审美验收，也不是本轮网页测试数量。

## 案例演示

实际 Prompt：**风格化蓝白纵向闪电，持续0.3秒**。

- 路线：教程局部机制 → 规则参数控制 → 明确 URP 配方 → 可编辑 Prefab → 实录对照。
- 环境：EffectDemo 2022，Unity 2022.3.62f3c1 / URP 14.0.12 / Direct3D11 / Linear。不混用 Unity 6。
- 资产：官方 URP 中性粒子材质模板的本地克隆，配合项目现有 `lightning1.png`；第三方贴图不默认具有公开再分发许可。
- 实录：每组 41 帧，0–0.4 秒，约每 0.01 秒一帧；效果本身为 0.3 秒，后 0.1 秒保留结束证据。页面是 PNG 帧回放，不是实时 WebGL。
- 三组：亮黑亮离散切换、连续渐变、透明度对照。默认暂停、0.25 倍速、循环关闭，含明暗闪烁提示。
- 交付：一个粒子系统、一个 Renderer 的局部 Prefab，未做 GPU 性能采样。

Prefab：`E:\Unity特效人工智能学习\UnityDemo\EffectDemo\Assets\Generated\TutorialLightningFixedColorR003\tutorial_fixed\GeneratedRoot.prefab`。

演示顺序建议：先展示亮黑亮实录，再看 0.07 秒黑形体与透明度对照，最后看原方案、只修颜色、明确配方三个制作版本。三个制作版本不是严格单变量视觉对照；灰色数值实验才是受控对照。

结论：已证明局部制作机制可执行，没有证明完整教程复现、专业成品质量、自动选材或完整风格理解。该案例不进入正式生成正例/SFT。
