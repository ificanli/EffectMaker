## 2. 跨集稳定规则

### 2.1 先保证主体和功能，再增加细节

特效首先要让人看懂主体是什么、从哪里来、打到哪里、何时结束。大爆点、碎片、闪电、火星和装饰元素不能代替核心轮廓、攻击方向和功能反馈。

### 2.2 形体、空间和动作必须互相承接

效果要与角色、武器、地面和镜头建立尺度关系。飞出、环绕、吸收、冲撞、蓄力、爆发和消散都需要前后因果；特效提前、滞后或突然消失都会削弱力量感。

### 2.3 核心最实，外围分层减弱

核心能量、主体刀光或爆点应最明确；外围气流、碎片、细线、残流和雾化层承担空间、方向和余波。所有层级同宽、同亮、同速会让画面扁平或嘈杂。

### 2.4 颜色是属性和层级系统，不是装饰堆叠

颜色需要贯穿效果生命周期，并与技能属性、主体层级和场景亮度匹配。蓝、白、金、红、紫等颜色随意增加，会造成风格漂移、视觉中心不稳定和观看疲劳。

### 2.5 动态不能只靠整体缩放或贴图平移

吸收、旋转、扭曲、流动和消散需要方向、速率、宽度、虚实、透明度和残留的组合变化。复杂效果应拆片、分速率、分层控制，以避免单张贴图循环僵硬。

### 2.6 减化同时服务美观、性能和画质档位

远景应减少重复资源和细节，中景保留主体轨迹，近景再增加丰富度。低配不应机械删除到只剩几个发射器，而要保留技能轮廓、主方向和功能语义。

## 3. 当前知识质量判断

### 已有价值

- **审美判断价值高**：前10集反复覆盖主体、层级、颜色、动态、空间、节奏和功能，已经形成稳定评审词汇和检查顺序。
- **迁移价值中高**：主体承接、核心/外围层级、颜色预算、残留收束、按景别减化等规则可迁移到刀光、雷电、冰、火、水和能量类效果。
- **流程价值高**：已经把“听懂”升级为“可定位、可回放、可引用、可追踪”的证据管道，后续资料投喂成本明显下降。
- **协作价值高**：Beads 认领、检查点 manifest 和分段产物使长视频可以中断恢复，多个窗口可以共享真实进度。

### 现有限制

- 目前主要是单一系列、单一讲师来源，存在观点偏差和重复强化，不能直接视为行业共识。
- 大部分规则仍是审美层判断，尚未在 Unity 场景中做 A/B 对照、性能采样或玩家可读性测试。
- 视频通常没有工程参数、贴图分辨率、Shader 设置、平台预算和真实战斗逻辑，不能据此推导具体数值规范。
- 第10集的代表案例取样已完成，但尚未对所有学员案例逐帧审计；报告中的“基本支持”和“待复核”必须保留。

## 4. 工作流复盘

### 已经验证有效的部分

1. 前台、单模型、固定600秒分段转写，比长命令和批量并行更稳定。
2. 分段 SRT 立即落盘，能够从中断窗口继续，不需要重跑整集。
3. 字幕只用于定位，关键帧和短片段负责视觉证据，降低了把口述误写成画面事实的风险。
4. 每集前中后三段报告比只写一篇长总结更容易复核和接管。
5. Beads 作为持久状态源，解决了多窗口认领、进度评论和任务关闭问题。

### 需要继续优化的部分

1. 将“转写 → 合并 → 证据 → 报告 → 建卡 → 索引”继续收敛到单集 orchestrator，但每个阶段必须可单独恢复。
2. manifest 增加阶段状态、最后成功窗口、失败原因、报告覆盖时间和卡片路径，作为接管入口。
3. 案例定位从人工查找升级为“字幕关键词候选 + 客观指标突变 + 人工确认”，不要让自动检测直接生成结论。
4. 统一案例目录命名和证据清单，避免预建空目录与实际案例目录并存。
5. 将每集的耗时、转写条目、案例数、关键帧数、人工复核覆盖率写入阶段统计，识别投入产出比。
6. 第11–20集先采用“完整转写 + 三段抽查 + 代表案例深核”的分级证据策略，只有高价值或争议案例才扩展到逐案例全量核对。
7. 每完成3–5集做一次跨集去重，把重复规则合并到系列规则页，单集卡片只保留新增差异。

## 5. 是否值得继续

结论：**值得继续，但应从“逐集完整加工”转为“分阶段、分证据等级、带复盘门槛地继续”。**

继续的理由：

- 前10集已经证明该系列能持续提供结构化的审美训练素材，而不是只有零散技巧。
- 规则已经覆盖从主体设计到动态、颜色、空间、层级、减化和功能兑现的完整审美链条。
- 这些判断可以直接转化为 Unity A/B 实验清单，具备从学习到制作的下一步价值。
- 后续集数可以检验规则是否稳定、是否出现反例，从而减少只凭单集印象建卡的风险。

继续的边界：

- 先推进到第20集，做一次第二阶段评估；不建议在没有跨来源和 Unity 验证前，把82集全部加工成同等可信度的稳定规范。
- 第11–20集优先寻找新主题、反例和重复内容；纯重复案例降低证据等级和处理深度。
- 每周至少挑选1条规则进入 Unity 对照实验，否则项目会停留在资料整理而不是能力增长。
